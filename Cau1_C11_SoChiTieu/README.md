# Câu 1 – Sổ chi tiêu cá nhân

Chạy `Database.sql` rồi chỉnh connection string trong `appsettings.json`. Project dùng EF Core SQL Server, cấu hình JSON, lọc ngày/nội dung/loại, tổng chi và log theo ngày ở `Logs/`.

Publish Framework-Dependent win-x64: `dotnet publish -c Release -r win-x64 --self-contained false`.
